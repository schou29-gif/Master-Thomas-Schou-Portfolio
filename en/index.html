Master data governance

Cleaned up years of inconsistent product data and introduced one fixed structure for all items.

25,000Products created for plast-line.dk
Master dataERPWMSAI
The challenge

Product data had been built up over a long time by different people. Items were created in the ERP system as a single combined line that didn't account for sizes and dimensions, so these couldn't be used as separate data.

What I did

Through hard work and with the help of AI, I cleaned up all the product data and split every item into separate fields – typically 7–8 attributes per product, including sizes and dimensions. At the same time I developed and implemented guidelines and workflows for how product, supplier and material master data is created and maintained.

The result

I have personally been responsible for creating all 25,000 products on plast-line.dk. This has led to better data quality, fewer operational errors and better use of the webshop.

From ERP to cloud PIM

Moved master data from ERP into Struct PIM in the cloud – with data mapping, testing and user training.

ERPStruct PIMCloudData mappingTraining
The challenge

Master data was held in the ERP system and had to be moved into Struct PIM, a cloud-based PIM solution – without data being lost or corrupted along the way.

What I did

I was responsible for moving master data from ERP to Struct PIM: data mapping, testing and validation, so the data came across correctly. Afterwards I trained the users so the new way of working became part of everyday routines.

The result

Product data is now managed in Struct PIM, separate from the ERP system. The data is cleaner and more consistent, and filters and search on the webshop work better.
